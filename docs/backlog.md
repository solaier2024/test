## 使用说明

- **复杂度**用 S / M / L / XL 表示相对规模,**不使用天/周估时**
- **状态**：`TODO` / `WIP` / `BLOCKED` / `DONE`
- `DEP` 列出前置任务 ID；无前置即可并行启动
- 验收标准不满足不算 DONE
- 本文件是活文档,推进时直接更新状态列

## 需要决策的事项

1. **是否现在开 `M3-1` 概念美术**（约 300 credits）？建议**等 M0 的 RTP 报告出来再投** —— 点球的决策面比拳击大,EV 中性校准可能反过来要求调整玩法参数,美术方向会跟着变。
2. **`X-3` 建议立即做** —— 成本低,但直接验证我们的差异点是否真的是竞品空白。
3. **拳击项目是否并行？** 若并行,`X-4` 的共享内核抽取应提前到 M0 阶段做,否则两套 PRF/模拟器会重复建设。
