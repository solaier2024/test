## 本轮实际更新（2026-10-09）

已完成阵容、三级压力、一次教练调整、公开策略自动防守、成长与三场杯赛，并加入浏览器内恢复。具体规则、性能与验证范围见 [实现记录](gameplay-and-performance.md) 和 [实际核对](gameplay-implementation-audit.md)。DONE 只标已有自动验证的本地实现，未代表正式服务端或商业上线。

S2-7/S3-2/S3-4 等为 WIP：中路进网与独立吊射共三条视频已获 3,000 积分预算，仍需生成与视觉检查。S1-1 原型专属动作尚缺；S1-5/8 的人群理解度与胜率套路深度不能用 EV 测试替代。S4-3 尚未达成 20–30 秒目标，S5-8 的杯赛核心已完成但 Liga MX 服装、横幅主题仍延期。基础穷举与生产扩展的分解证书分别记录，不夸大全 seed 覆盖。

## v2 相对 v1 的变化

阶段体系由 `M0–M5` 改为 **`S0–S5`**,原因是 v1 的 EV 中性论证在数学上不成立（详见设计方案 §0）,验证方式与首版范围都需重排。

| 变化 | 说明 |
|---|---|
| **新增完整状态求解任务** | 原 v1 只有蒙特卡洛,不构成"全策略证明"。新增 `S0-7` 求 Vmax/Vmin 边界 |
| **新增现金价值鞅模型任务** | `S0-4`/`S0-5`,替代 v1 的"命中率 × 步进恒等"校准 |
| **新增无损区间检查** | `S0-8` 是 S0 的出口门禁 —— v1 的示例存在该缺陷 |
| **首版操作面缩减** | 7 区 × 2 力道 → **3 方向 × 2 射法**；防守 3 方向；压力/阵容/快速模式后置 |
| **完美大战现金加成移除** | 与提前锁胜逻辑冲突,改为非金钱成绩 |
| **双倍罚球移出首版** | 数学条件需 p=50% 或改 C/p 赔付 |
| **快速模式后置到 S4** | v1 的"共用 PRF 即同 RTP"论证不足 |
| **新增片段覆盖验证** | `S3-2`,先验证再冻结片单（v1 直接把 16 条当结论） |
| **新增数据契约任务** | DecisionQuote / DecisionEvent / Settlement、幂等、竞态、版本固定 |
| **新增玩家试玩验证** | `S1-8`,8–12 名测试者的理解度验证 |

## S0 — 结算灰盒（首版必做）

目标：建立完整的状态与终局表,把现金模型做对。**零美术投入。**

| ID | 任务 | 复杂度 | DEP | 状态 | 验收标准 |
|---|---|---|---|---|---|
| **S0-1** | 搭 `shootout-math` 纯 JavaScript 模块（零依赖、Node 可运行、自动测试） | S | — | DONE | 无浏览器环境下 `npm test` 通过；包内无 DOM/Pixi 引用 |
| **S0-2** | 带种子 PRF：`PRF(seed, 轮次, 阶段, 决策路径)` | M | S0-1 | DONE | 同 seed + 同路径 1000 次重放一致；攻防分支互不相关；通过均匀性检验 |
| **S0-3** | 基础动作模型：**3 方向 × 2 射法 = 6 组合**,防守 3 方向 | M | S0-2 | DONE | 各组合条件概率可配置；100% 分支覆盖 |
| **S0-4** | **现金价值模型 `C(s)`,允许随结果下降** | L | S0-3 | DONE | 失败分支使 `C` 下降；`C(s₀) = W × r`；终局 `C(s) = G(s)` |
| **S0-5** | **鞅条件求解器**：求满足 `C(s) = Σ P(s'\|s,a) C(s')` 的参数 | XL | S0-4 | DONE | 对每个可达决策状态与每个合法继续动作成立；输出校准报告；无法满足时明确报告冲突节点 |
| **S0-6** | 完整赛制与终局表：5 轮、提前锁胜、限定骤死（≤3 组）、平局返还 | L | S0-3 | DONE | 16 个罚球阶段上限正确；提前锁胜后关闭继续/收钱/调整入口；自动结算一次 |
| **S0-7** | **完整状态求解 Vmax / Vmin 边界** | XL | S0-5, S0-6 | DONE | `Vmax(s₀) = Vmin(s₀) = W × r`（容差以百分点表达）；定位所有不一致节点；状态覆盖范围明确记录 |
| **S0-8** | **无损继续区间检查**（S0 出口门禁） | M | S0-7 | DONE | 不存在任何"继续严格优于收钱"的可达状态；该检查进 CI |
| **S0-9** | 蒙特卡洛回归工具 | L | S0-6 | DONE | 输出 RTP、取胜率、赢钱概率、方差、现金分布、终局路径占比、**样本量与置信区间**、尾部事件覆盖 |
| **S0-10** | 无美术调试 UI（纯 HTML,暴露全部内部状态） | M | S0-6 | WIP | 可手玩完整一场含骤死；可见比分、双方剩余次数、**当前可兑现金额**、记忆、seed、报价标识 |

**S0 出口条件**：状态与终局表完整；求解范围明确；**无无损增值区间**；`Vmax = Vmin = 目标 RTP`。
