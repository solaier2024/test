# 资源来源

| 当前使用的资源 | 来源与处理 |
| --- | --- |
| 写实开场、首帧、比赛待机 | OpenArt / Seedance 2.0，本项目提示词生成；原片、任务、参数见 `seedance-jobs.json`。不标为 CC0。待机取同源前段做正反循环；竖屏待机保持完整球门并使用模糊填充。 |
| 动作结果短片 | 尚待生成与验收；只允许批准素材进入生产清单。 |
| Barlow / Barlow Condensed | [Barlow Project](https://github.com/jpt/barlow)，SIL Open Font License 1.1；经 Fontsource 获取，本地托管。中文使用系统字体。 |
| 鼓点、拍手、低吟、哨声、击球、欢呼 | 项目自编 Web Audio 声场；原创无词低吟与四小节变奏。试听来自同一引擎的离线渲染。 |
| 图标和游戏界面 | 项目代码生成，PixiJS / SVG / CSS。 |

旧的 Kenney GLB、球衣源 SVG、程序球场和录制庆祝仅保留为历史实验资源，当前主入口与视频清单均不播放它们。Kenney 来源为 [Animated Characters Protagonists](https://kenney.nl/assets/animated-characters-protagonists)，CC0，授权文本位于 `public/assets/models/Kenney-LICENSE.txt`。字体授权文本位于 `public/assets/fonts/Barlow-OFL.txt`。

参考游戏仅用于构图和交互观察，未复制其资源。
