# 点球大赛：玩法实际实现核对

更新：2026-10-10，`psc-0.3.0-depth-v1`。依据 [v2 设计](gameplay-design.md)、[独立补充稿](gameplay-depth-proposal.md) 与实际源码。规划、生成预算不等于通过验收。

| 设计条目 | 实际状态与行为 |
| --- | --- |
| 五轮、提前结束、三组骤死、平局结算 | 已实现。修复骤死提前一组结束，严格最多 16 个罚球阶段；修正扳平和必胜提示边界 |
| 概率、双分支报价、轮末收取、幂等 | 已实现。同一不可变报价用于抽样和现金推进，旧报价不能执行其他动作，终局最后一球重复提交幂等 |
| 三类门将、赛前简报与记忆 | 数值已实现。简报与实际开局一致，记忆有衰减与上限；原型专属准备姿态和扑救节奏仍缺视频表现 |
| 手机线索、双方记录 | 已实现常驻押向／威胁权重与剩余次数。自己的射向、对手实际球路、玩家扑向分别记录。固定片段按结果匹配，视频方向样本不能冒充独立采样的射手频率 |
| 五人阵容与排序 | 六人选五人，换人、上移／下移、默认、沿用上场；原始顺序绑定决策路径。常规每人一球，骤死从首位轮转 |
| 神射手／重炮／冰血／艺术家 | 推射 +5.5、抽射 +7、独立吊射 +7.5 个百分点。冰血只免本人射门压力项，仍受记忆和随机结果影响。独立中路吊射已使用合格成功／失败视频开放 |
| 三级压力 | 近期失败升一级，进球／扑救降一级，范围 0…2；落后有中压下限，第五轮和骤死有高压下限。概率与现金分支同步重算 |
| 每场一次教练调整 | 完整轮末且至少两人未出场时交换两人；保留比分、现金、压力与记忆，留下不可回滚事件与新报价 |
| 完整与快速模式 | 快速模式按公开扑救概率最高方向自动防守，同率按左／中／右排序。保留全部视频和轮末收取，不宣称达到 20–30 秒 |
| 战报与重演 | 2–3 条真实事件摘要、实际命中次数、球员、压力、概率、球路／扑向、调整、返还；按揭示种子、配置、初始阵容与完整路径验证 |
| 成绩、称号、球衣、图鉴 | 七项成就、经验等级、佩戴称号、四款球衣徽章、三类对手图鉴；仅外观成长，拍摄视频服装固定 |
| 三场杯赛 | 八强／半决赛／决赛，不同公开对手。每场独立种子、投入和结算；胜利晋级，平局／落败／主动收取退出本届，无连场资金加成 |
| 浏览器内恢复 | 按存档重演恢复原结果和报价，成长去重；存储不可用时继续内存比赛。不是跨设备账户同步 |
| MP4、动态观众、开场与现场声 | 动态待机、八种标准结果动作、两种独立吊射结果均已接入横竖版。三路进攻与防守；无字／无倒计时开场，默认声音，手动与自动扑救均有哨声，心跳呼吸随真实压力变化 |
| 英语／西班牙语 | 全部游戏屏幕、弹窗、Pixi 标签、加载／错误及无障碍文案可切换。记住偏好，保留比赛状态和未提交的面板编辑 |

## 本轮补片已接入

中路进网、独立中路吊射进网／接住三条此前已批准任务均完成并通过方向、单球、轨迹、看台及触球时间核对。方案与任务记录见 [视频补齐方案](gameplay-video-completion-plan.md)。标准动作 8/8、独立吊射 2/2；未再提交付费任务。

独立吊射只允许中路，有自己的概率和波动。导入工具额外要求上升／下降弧线确认；成功和失败片均通过核对，新比赛自动启用。旧存档的冻结配置保留，不在中途改变概率或报价。

墨西哥绿／美国深蓝服装与横幅主题重做继续延期。上下角、扑救时机、双倍分支、PvP 属后续扩展。

## 性能与验收

HUD 从持续 45 FPS 改为按需绘制；所选球路延迟预加载两种结果，省流量和 2G 不做投机预载；缓存四条且不超过 8 MiB，保护在播 Blob；隐藏页面暂停待机与声音。字体和声音额外首屏等待上限 1.5 秒，声音晚到仍可解码，声音故障不阻止比赛。

规则、报价、调整、自动防守、成长、恢复、视频矩阵与数学回归结果见 [玩法与性能记录](gameplay-and-performance.md)。基础方向记忆穷举与生产扩展分解 Bellman 证书分别记录，不能把有限 seed 样本当成连续倾向的穷举。

8–12 人理解度试玩、人群整局 P50/P95/P99、低端 Android 实机与限速网络尚未验收。自动化检查不能证明留存、胜率套路的丰富程度或正式服务端公平性。
