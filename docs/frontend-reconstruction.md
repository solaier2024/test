# LAST KICK 前端重构

当前表现使用 **PixiJS + GSAP + Vite / Rolldown + 视频基底**。球场、球员、球路和扑救动作由 MP4 呈现；比分、选路、报价和控制由 Pixi 绘制。Provider 继续决定结果，媒体不会影响成功率。主入口不加载 PlayCanvas。

## 开场与动作

开场直接播放 Seedance CG，结束后进入首球。已删除标题、英文标语、倒计时、进度条和覆盖渐变；只有无文字的跳过图标。减弱动态效果时跳过开场和待机循环，用户主动触发的射门仍播放真实视频。

每球按 `goal/save-球路-门将方向` 选择已验收视频，方向均以射手视角为准。现有八条 Seedance 任务均已完成；动态待机及七种实际动作已接入。原 `goal-C-R` 实际射向右路、门将也右扑，对中路需求验收不通过；经实际画面复核，它作为 `goal-R-R` 接入成功的右路抽射，保留真实球路。比赛可以使用左右路进攻、三路防守；中路进攻显示“视频待补齐”且禁用，开局自动选择可用方向。权威报价仍保留完整合法动作，不用缺片改变概率或结果。其他方向的推射／抽射仍共享结果片；右路抽射新增同侧门将未扑到的真实进球画面，不能据此宣称整包已有独立射法动作。

左路扑救保留 0–3.541667 秒的真实出脚、球路及手套拦截，截掉约 3.58 秒起出现第二个足球的生成尾段。结束时是扑救接球姿势；没有拼接相反结果或伪造落地。任务、触球时间和裁切记录见 `seedance-jobs.json` 与 `video-integration-review.md`。

缺片时在调用 Provider 之前停止本球提交；没有消耗球次、改比分、改返还或产生结果。待机观众动态及成功／失败两条视频的观众反应均需通过审看，两条匹配视频还须下载成功，之后才允许提交。已删除缺片时的文字结果替代以及覆盖动作的大字提示。发生实际播放中断时保留已接受结果，支持用回放重看同一视频。

动态待机采用 8.04 秒的正常向前播放视频，不倒放拍手、旗帜或人群起立。两侧看台可见旗帜摆动及不同人群的姿态变化，进球片有多区举臂反应。固定球门、静止待机球和首尾前景姿态已审看。旧待机不再被主清单引用。`tools/import-stadium-loop.py` 和 `tools/import-shot-clip.py` 只有显式提交动态观众审看记录后才更新生产清单；旧 CG 提取工具不能覆盖已验收的动态待机。

视频触球与结果音由 `requestVideoFrameCallback` 的媒体时间驱动，不支持该 API 时使用 `timeupdate`。回放不调用 Provider，播放期间隐藏比赛与结算面板，结束或失败后恢复布局和待机。待机 `play()` 的异步取消只作用于旧播放，不会暂停新射门或回放。每条视频带 poster，缓存只保留最近四条动作，销毁时释放 Blob URL。手机素材使用保全球门的 4:3 裁切加同源模糊上下填充，属于横片适配，不是原生竖屏拍摄。

## 现场声音

声音默认开启，首次点击进入球场后建立 AudioContext。近处为双拍心跳和真实男性呼吸，远处为立体声观众呼喝、鼓掌及欢呼；看台具有延迟反射，呼吸保持干声。已删除合成低吟和旋律。

心跳常规约 78–92 BPM，开场 94 BPM，提交准备时约 104–118 BPM。关键球提高心跳与呼吸强度；实际触球时压低这两层及节奏，结果时播放录制的观众反应。鼓点与分散拍手走独立节奏。静音停止排程和声源，切到后台暂停，恢复时不会追放积压节拍。声音不申请麦克风权限。

四段实录来自 Freesound 的 CC0 素材，按原始网页公开的高清预览地址取得，处理包括滤波、音量归一化、首尾淡化和 MP3 打包。新增真实裁判哨声：CG 或阶段准备结束、交互恢复后响一次，玩家和对手罚球均覆盖；按 quoteId 去重，选路、失败重试和回放不会重复吹哨。静音或后台不补播错过的哨声。来源与作者见 `asset-credits.md`。试听导出使用与比赛完全相同的 Web Audio 图，文件为 `previews/stadium-live.mp3`。

## 验证与开发

`npm test` 检查规则、单次提交、报价锁、缺片或未验收看台不提交、媒体下载失败重试、回放隔离和动作映射。`npm run verify:assets` 检查清单文件、已批准动作映射、音频和 HTMLPreview 经典脚本。加入同侧门将失球后，完整动作包需要八种实际组合，并覆盖攻防、方向、两种射法及两种结果；待机／动作看台均需通过审看。当前七种已接入，清单仍标为 partial。

开发模式 `?audio-preview=1` 导出 24 秒 WAV；`?clip-preview=1` 可选择七种已批准动作，使用实际视频场景播放并保留终帧，不调用 Provider。审看控件位于画面外，开发工具不进入生产包。浏览器证据见 `browser-qa.md`。
