# 点球游戏：玩法补齐与性能改进

版本 `psc-0.3.0-depth-v1`，2026-10-10。记录实际实现、测试范围与待完成部分。

## 完整游戏循环

赛前简报与本次开局一致，在六名球员中安排五人顺序；选择完整／自动防守模式、单场／三场杯赛。逐球观察出场球员、特质、真实压力、对手押向与结果分支报价，通过实际 MP4 完成攻防。轮末决定收取、继续或使用一次教练交换。终局展示真实关键事件、成绩与日志重演；杯赛获胜晋级，每场重新投入并独立结算。刷新时恢复原比赛，成长按结算编号去重。

## 参数与操作边界

神射手推射加 0.055，重炮抽射加 0.07，艺术家独立中路吊射加 0.075。冰血只屏蔽本人射门压力扣减。概率最终限定 `[0.20, 0.93]`，不保证进球。

| 压力 | 推射扣减 | 抽射扣减 | 吊射扣减 | 扑救扣减 |
| --- | --- | --- | --- | --- |
| 低 | 0 | 0 | 0 | 0 |
| 中 | 0.035 | 0.055 | 0.04 | 0.025 |
| 高 | 0.075 | 0.11 | 0.09 | 0.055 |

近期未进／失球升一级，进球／扑救降一级，范围 0…2。比分落后至少中压，第五轮与骤死至少高压；成功恢复近期项，不抹除比分情境。神射手、重炮仍受压力与门将记忆影响。

每份不可变报价使用同一个 `p` 计算和抽样：`d=risk`，失败直接落败则 `d=1`；`u=d(1-p)/p`。成功为 `C(1+u)`、失败为 `C(1-d)`。教练交换现金不变、消耗一次次数、发布新报价；原始阵容与完整调整日志绑定路径。

快速策略 `public-max-save-v1` 只读公开扑救概率，最高者优先，同率 L/C/R。保留实际对手视频和轮末收取。没有用共用 RNG 代替模式验证，也不宣称整局已达到 20–30 秒。

杯赛八强／半决赛／决赛使用不同原型和公开倾向。只在独立结算获胜时晋级，平局／失利／主动收取结束本届。成长仅涉及七项成就、经验、称号、球衣徽章和图鉴；当前视频服装固定，外观不进入概率、现金或 PRF。

- 基础比分／方向记忆求解：6,259,392 次 Vmax／Vmin 状态访问。投入 10 的目标为 9.6，最大偏差 `1.243e-14`。
- 基础无损检查：306,972 个收取窗口，无继续期望高于当前现金的区间；失败均降值。
- 扩展分解 Bellman 证书：229 个可达比分／阶段状态，293 个 Bellman 节点，720 种五人顺序，46,800 个合法交换，29,523 个历史上下文，9,919,764 个具体报价，240 场完整重演。`PhiMax=1`，`PhiMin=0.9999999999999992`。
- 具体报价检查覆盖三原型、四个公开倾向、四种特质、三级压力和独立吊射规则。**不是所有连续倾向／seed 的笛卡尔积枚举**。一般条件的归纳依赖逐报价运行时恒等式、最多 16 球与一次教练的有限路径。
- 蒙特卡洛 23 类策略 ×20,000 场，共 460,000 场，包括提前／压力触发／后置交换、反向阵容、自动防守、吊射数值、三杯赛对手。报告 95% CI，最大区间外偏差为 0（容差 0.002），执行 78,074 次教练调整。样本最大 346.3 倍，不能称为覆盖所有尾部。数值中的吊射不代表生产视频可用。
- 最后结算才舍入，绝对误差上界 0.005 MXN。归纳针对未舍入现金，不掩盖最终金额精度。

单测覆盖完整三组骤死、关键球边界、压力恢复、特质／记忆联动、教练合法范围、报价不可变、终局重复提交、真实球路、自动防守失败重试、杯赛收取退出、损坏存档、完整日志篡改检测和缓存体积。浏览器证据另见 `browser-qa.md`。

## 性能改变

| 问题 | 实现 |
| --- | --- |
| 待机 HUD 持续 45 FPS 重绘 | 关闭常驻 ticker，仅在状态、尺寸和 GSAP 交互变化时合并到一个 rAF 绘制 |
| 点击确认后开始下载 | 选定球路 160 ms 后只预载当前两种结果；省流量与 2G 不做投机请求 |
| 只限条目，无法限内存 | 四条且 8 MiB 的 Blob 缓存，在播资源 pin，淘汰和销毁释放 URL |
| 声音／字体延迟堵塞首屏 | 并发请求，额外等待最多 1.5 秒；字体到达一次重绘，晚到音频逐样本解码，成功后释放压缩字节 |
| 后台继续待机和声音 | 暂停待机与声调度，返回恢复；已接受动作不重抽 |
| 刷新丢状态，成绩重复增加 | 保存种子、冻结配置、初始阵容、动作日志，重演恢复原报价并按结算编号去重 |

继续保持外置 land／port／poster 和像素密度上限 2。首屏 JS/CSS gzip 与外置视频整包分别统计，不能把整包大小当成首屏下载量。三条补片已完成转码、保全球门裁切、poster 和触球时间核对。切换语言仅重绘 HUD 和现有弹窗，不重新下载影片、初始化比赛或启动常驻渲染。

当前 `public/assets` 共 74 文件、26,031,695 字节（26.03 MB，24.83 MiB）。超过原计划的十进制 20 MB 整包目标，不能标记达标；它不是一次性首屏下载。新增动作按当前选择分批预载，继续沿用四条／8 MiB 缓存限制。桌面浏览器检查不能替代低端 Android 的内存、温度和播放帧率验收。
