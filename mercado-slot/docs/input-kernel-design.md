# 输入玩法方案的实现摘录

来源：用户提供的 `street-food-slot-kernel-design.md`。此处记录开发采用的首代规则；原文件仍保留在用户原位置。完整市场调研和内部资料引用不属于此代码交付。

| 项目 | 首代约定 |
| --- | --- |
| 主题 | 墨西哥街头食物，原创名称 Mercado de Oro |
| 主盘 | 三列三行，五条固定线 |
| 第四列 | 纯倍率轴，仅中间值参与结算，不参与中奖线 |
| 倍率 | ×1、×2、×3、×5、×10、×15 |
| Wild | 黄金塔可，替代普通食物；全 Wild 线为 25 倍单线基础投注 |
| 奖励流程 | 主盘揭示后揭示倍率，中奖线合计再乘一次倍率 |
| Extra Salsa | 实际支付多 50%，移除 ×1，提高 ×15 概率；目标 EV 中性、提高归一化波动 |
| 首代最大赔付 | 375 倍基础投注；Extra 为实际支付的 250 倍 |
| 理论 RTP 目标 | 两种模式均为 96.5% |
| 局内决策 | 0；下注与模式在旋转前确定 |
| 首代排除 | 无 Bonus、免费旋转、收集系统、摊位选择或额外整盘奖励 |
| 后续产品方向 | 更高倍率、Nudge 和连锁作为独立产品／配置评估 |

普通食物包括 tortilla、chile、lime、avocado、esquite、tamal、taco，黄金 taco 为 Wild。所有符号和概率是本游戏的独立实现；Fortune Gems 的未公开概率及公开描述中的部分歧义不作为等价承诺。

输入方案的“中低波动”是产品目标。首版使用独立联合求解配置，已记录实际标准差、命中率和净盈利概率；会话体验与实机测量尚待验收。完整交互定义见 [交互与技术设计](interaction-and-technical-design.md)，实际状态见 [README](../README.md)，概率与可达最大值见 [数学报告](math-certificate.json)。
