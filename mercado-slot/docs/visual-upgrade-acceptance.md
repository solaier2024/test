## 开场触发修正

移除持久化的 guide／guideV2／entranceSeen 跳过标记。先前在同一浏览器进行验收会把这些标记写为 true，随后用户进入时跳过 CG 和说明。当前进入流程只以本次页面的 entered 控制重复点击，不再以保存的已读状态决定是否播放／展示。每次重新加载都恢复 ENTER／ENTRAR；主动请求播放 CG 时不会被减少动态偏好静默跳过，轴条和 CSS 的减少动态设置继续生效。

本地同一浏览器带已保存历史重复加载验收：第一遍正常播放 CG 并自动弹教学；关闭教学再刷新，第二遍仍播放 CG，点击 Saltar 后仍弹教学。过程中余额保持 973.20，没有新增开奖或重置历史。

另修复切源时过期的环境 play() Promise：背景请求因切换 CG 被取消后，不得清除 CG 的 video-playing 类或把它标记为 fallback。每次播放／释放使用独立尝试编号，只有当前环境请求可以修改环境失败状态；后台恢复 CG 也检查所属 generation。新增两项异步回归先在旧逻辑下复现失败，再在修复后通过。

## Seedance 素材和审核

用户批准 1,760 积分，实际完成相同的三条配置。原始素材、输出 URL 和任务号记录在 video-generation-journal.json。抽帧使用 mp4-frame-extractor 技能；检查固定环境镜位、暖色灯光、蒸汽／远景人群、原创食物 CG、无文案／数字／倒计时。生成横屏 1280×720、竖屏 720×1280、CG 1920×1080，24fps；CG 有 AAC 音轨，环境无音轨。

环境前后 0.5 秒采用正向溶解衔接，成品 5.5 秒，人物不反向移动。环境分别 441,097／323,359 字节，CG 1,036,004 字节、4 秒。所有 MP4 使用 H.264、yuv420p、fast-start，索引在样本之前。自产 CG 提取的 grill-ambience.m4a 为 12,939 字节。SHA-256、字节、尺寸、音轨和预算经过资源检查。

运行只有一个 HTMLVideoElement，在环境、竖屏环境与 CG 之间释放并切换源。环境播放静音循环，CG 经主动点击播放，可跳过、结束或加载失败后回到同一游戏。页面隐藏暂停视频、GSAP 和 AudioContext；动态场景关闭则释放 src。网络不可用时保留专用海报与完整规则／账本。
